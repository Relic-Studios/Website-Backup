Engram

View the repository{{> icon name=right}}

Engram is an agent memory project published under Relic-Studios on GitHub. Its README credits Aidan Poole and Relic Studios as the author. It addresses a basic limit of language-model agents: they do not keep memory from one session to the next.

Four memory layers

  • Episodic: what happened. Conversations, events and moments.
  • Semantic: what the agent knows. Relationships, preferences and boundaries.
  • Procedural: how to do things. Skills and processes.
  • Working: what matters right now. Context assembled within a token budget.

Engram runs as an MCP (Model Context Protocol) server.
