ATLAS Voice

Created by Aidan Poole (Relic). Published by Relic Studios.

Download for Windows{{> icon name=right}} Watch the demo

ATLAS Voice is a Windows application created by Aidan Poole through Relic Studios for AI voice agents in group conversations. Its published features include speaker awareness, conversational turn-taking, streaming speech and configurable voices. Local-model and provider-backed modes are described in the official release documentation. ATLAS 1.0 is free to use and closed source; the public GitHub repository hosts its official releases.

The application and its documentation use the name ATLAS.

What it does

  • Joins a group call, answers when it is addressed and stays quiet when it is not.
  • Labels each speaker and learns names from introductions.
  • Starts speaking while the rest of the reply is still being generated.
  • Lets you create your own agent from a short voice clip and a description of its personality.
  • Runs the AI model on your own NVIDIA graphics card, or uses an API provider you choose for the model.
  • Ships with optional plugins that stay off until you turn them on.
  • Needs no account and sends no telemetry.

System requirements and installation steps are in the official README.
